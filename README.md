# 結果画像

↓動画にした方が分かりやすい変更を加えたので画像ではなく動画を貼らせていただきます。
-(https://github.com/user-attachments/assets/1e5d6e9c-d64a-4a25-b611-078cf3c6a4bd)
- 作ったもの：幽霊
- 工夫した点：講義で学んだフレネルを応用し、カメラが見ている方向に対して横を向いた時ほど不透明度が強くなるようにして、ふちがぼんやり光る半透明の幽霊を表現しました。
- さらにそれだけでは少し物足りなかったので、ワールド座標を参照して揺らしました。
- また、高さごとに揺らすタイミングをずらすことで、より幽霊のようなグネグネした動きを表現しました。
